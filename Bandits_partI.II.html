Concentration of Measure

Definition 5.2 Subgaussianity

  • An R.V. is $\sigma$-subgaussian if $$\mathbb{E}\left\lbrack {\exp \left( {\lambda X}\right) }\right\rbrack \leq \exp \left( {{\lambda }^{2}{\sigma }^{2}/2}\right)$$.

    • Theorem 5.3 - for one subgaussian R.V.

  • If $X$ is $\sigma$-subgaussian, $$\mathbb{P}\left( {X \geq \varepsilon }\right) \leq \exp \left( {-\frac{{\varepsilon }^{2}}{2{\sigma }^{2}}}\right) $$

    • Corllary 5.5 - for several subgaussian R.V.s

  • If $X_i-\mu$ are independent, subgaussian R.V., then $\forall \varepsilon$, $$\mathbb{P}\left( {\widehat{\mu } \geq \mu + \varepsilon }\right) \leq \exp \left( {-\frac{n{\varepsilon }^{2}}{2{\sigma }^{2}}}\right) \;\text{ and }\;\mathbb{P}\left( {\widehat{\mu } \leq \mu - \varepsilon }\right) \leq \exp \left( {-\frac{n{\varepsilon }^{2}}{2{\sigma }^{2}}}\right) ,$$ where $\widehat{\mu } = \frac{1}{n}\mathop{\sum }\limits_{{t = 1}}^{n}{X}_{t}$.

    • Theorem 9.2 - strengthened version of collary 5.5

  • If ${X}_{1},{X}_{2},\ldots ,{X}_{n}$ are independent $\sigma$-subgaussian R.V., and ${S}_{t} = \mathop{\sum }\limits_{{s = 1}}^{t}{X}_{s}$, then $\forall\varepsilon$, $$\mathbb{P}\left( {\text{ exists }t \leq n : {S}_{t} \geq \varepsilon }\right) \leq \exp \left( {-\frac{{\varepsilon }^{2}}{{2n}{\sigma }^{2}}}\right) . $$

    • Lemma 10.3 Chernoff's Bound for Bernouli Noise

  • Let $\frac{1}{n}\mathop{\sum }\limits_{{t = 1}}^{n}{X}_{t}$, then for $\varepsilon \in \left\lbrack {0,1 - \mu }\right\rbrack$ $$\mathbb{P}\left( {\widehat{\mu } \geq \mu + \varepsilon }\right) \leq \exp \left( {-{nd}\left( {\mu + \varepsilon ,\mu }\right) }\right) $$ for $\varepsilon \in \left\lbrack {0,\mu }\right\rbrack$ $$\mathbb{P}\left( {\widehat{\mu } \leq \mu - \varepsilon }\right) \leq \exp \left( {-{nd}\left( {\mu - \varepsilon ,\mu }\right) }\right) . $$

    Stochastic Bandits

    Definition of Bandit and Environment

  • A bandit is defined as a collection of the distributions of the reward of each arm$$\nu = \left( {{P}_{a} : a \in \mathcal{A}}\right) $$
  • A set of bandits is called an environment class$$\mathcal{E} = \left\{ {\nu = \left( {{P}_{a} : a \in \mathcal{A}}\right) : {P}_{a} \in {\mathcal{M}}_{a}\text{ for all }a \in \mathcal{A}}\right\} $$
  • Classification of bandits: structured bandits and unstructured bandits, the latter composed of parametric and non-parametric bandits.

    • ETC Strategy

  • Each arm is played a fixed number of rounds, $m$, following which the arm with the optimal empirical mean reward will be chosen in each future round.

    Upper Confidence Bound

    Proof of Theorem 7.1 - reciprocal of gaps

  • Define a good event ${G}_{i} = \left\{ {{\mu }_{1} < \mathop{\min }\limits_{{t \in \left\lbrack n\right\rbrack }}{\mathrm{{UCB}}}_{1}\left( {t,\delta }\right) }\right\} \cap \left\{ {{\widehat{\mu }}_{i{u}_{i}} + \sqrt{\frac{2}{{u}_{i}}\log \left( \frac{1}{\delta }\right) } < {\mu }_{1}}\right\} ,$
  • Decompose the regret into two parts: $R_n = R_n(G_1) + R_n(G_1^c)$, which means decomposition of $$\mathbb{E}\left\lbrack {{T}_{i}\left( n\right) }\right\rbrack = \mathbb{E}\left\lbrack {\mathbb{I}\left\{ {G}_{i}\right\} {T}_{i}\left( n\right) }\right\rbrack + \mathbb{E}\left\lbrack {\mathbb{I}\left\{ {G}_{i}^{c}\right\} {T}_{i}\left( n\right) }\right\rbrack $$
  • For the first term, we have ${T}_{i}\left( n\right) \leq {u}_{i}$, proved by contradiction.
  • For the second term, we have $\mathbb{P}\left( {G}_{i}^{c}\right) \leq {n\delta } + \exp \left( {-\frac{{u}_{i}{c}^{2}{\Delta }_{i}^{2}}{2}}\right) .$
    • ${G}_{i}^{c} = \left\{ {{\mu }_{1} \geq \mathop{\min }\limits_{{t \in \left\lbrack n\right\rbrack }}{\mathrm{{UCB}}}_{1}\left( {t,\delta }\right) }\right\} \cup \left\{ {{\widehat{\mu }}_{i{u}_{i}} + \sqrt{\frac{2\log \left( {1/\delta }\right) }{{u}_{i}}} \geq {\mu }_{1}}\right\} $
    • For the first subset, we have $$\mathbb{P}\left( {{\mu }_{1} \geq \mathop{\min }\limits_{{t \in \left\lbrack n\right\rbrack }}{\mathrm{{UCB}}}_{1}\left( {t,\delta }\right) }\right) \leq \mathbb{P}\left( {\mathop{\bigcup }\limits_{{s \in \left\lbrack n\right\rbrack }}\left\{ {{\mu }_{1} \geq {\widehat{\mu }}_{1s} + \sqrt{\frac{2\log \left( {1/\delta }\right) }{s}}}\right\} }\right)$$
    • For the second subset, we have $$\mathbb{P}\left( {{\widehat{\mu }}_{i{u}_{i}} + \sqrt{\frac{2\log \left( {1/\delta }\right) }{{u}_{i}}} \geq {\mu }_{1}}\right) = \mathbb{P}\left( {{\widehat{\mu }}_{i{u}_{i}} - {\mu }_{i} \geq {\Delta }_{i} - \sqrt{\frac{2\log \left( {1/\delta }\right) }{{u}_{i}}}}\right)$$, by assuming that $${\Delta }_{i} - \sqrt{\frac{2\log \left( {1/\delta }\right) }{{u}_{i}}} \geq c{\Delta }_{i} $$
    • Therefore, $\mathbb{P}\left( {G}_{i}^{c}\right) \leq {n\delta } + \exp \left( {-\frac{{u}_{i}{c}^{2}{\Delta }_{i}^{2}}{2}}\right) .$
  • Hence, $$\mathbb{E}\left\lbrack {{T}_{i}\left( n\right) }\right\rbrack \leq {u}_{i} + n\left( {{n\delta } + \exp \left( {-\frac{{u}_{i}{c}^{2}{\Delta }_{i}^{2}}{2}}\right) }\right) . $$ where ${u}_{i} = \left\lceil \frac{2\log \left( {1/\delta }\right) }{{\left( 1 - c\right) }^{2}{\Delta }_{i}^{2}}\right\rceil .$
  • Finally, $$\mathbb{E}\left\lbrack {{T}_{i}\left( n\right) }\right\rbrack \leq 3 + \frac{{16}\log \left( n\right) }{{\Delta }_{i}^{2}}.$$ and$$ {R}_{n} = \sum_{i=1}^k \Delta_i\mathbb{E}\left\lbrack {{T}_{i}\left( n\right) }\right\rbrack \leq 3\mathop{\sum }\limits_{{i = 1}}^{k}{\Delta }_{i} + \mathop{\sum }\limits_{{i : {\Delta }_{i} > 0}}\frac{{16}\log \left( n\right) }{{\Delta }_{i}}. $$

    • Proof of Theorem 7.2 - linear in gaps

  • Decompose the regret by $\Delta$: $${R}_{n} = \mathop{\sum }\limits_{{i = 1}}^{k}{\Delta }_{i}\mathbb{E}\left\lbrack {{T}_{i}\left( n\right) }\right\rbrack = \mathop{\sum }\limits_{{i : {\Delta }_{i} < \Delta }}{\Delta }_{i}\mathbb{E}\left\lbrack {{T}_{i}\left( n\right) }\right\rbrack + \mathop{\sum }\limits_{{i : {\Delta }_{i} \geq \Delta }}{\Delta }_{i}\mathbb{E}\left\lbrack {{T}_{i}\left( n\right) }\right\rbrack$$ $$\leq {n\Delta } + \mathop{\sum }\limits_{{i : {\Delta }_{i} \geq \Delta }}\left( {3{\Delta }_{i} + \frac{{16}\log \left( n\right) }{{\Delta }_{i}}}\right) \leq {n\Delta } + \frac{{16k}\log \left( n\right) }{\Delta } + 3\mathop{\sum }\limits_{i}{\Delta }_{i}$$ $$\leq 8\sqrt{{nk}\log \left( n\right) } + 3\mathop{\sum }\limits_{{i = 1}}^{k}{\Delta }_{i}$$
