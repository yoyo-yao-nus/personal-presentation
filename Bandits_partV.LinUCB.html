Stochastic Linear Bandits - LinUCB

LinUCB Algorithm

  • \[{\mathrm{{UCB}}}_{t}\left( a\right) = \mathop{\max }\limits_{{\theta \in {\mathcal{C}}_{t}}}\langle \theta ,a\rangle \tag{19.2}\]
  • Select \[{A}_{t} = {\operatorname{argmax}}_{a \in {\mathcal{A}}_{t}}{\mathrm{{UCB}}}_{t}\left( a\right) . \tag{19.3}\]

    • \(\mathcal{C_t}\) the confidence set of \(\theta_\star\) at time \(t\)

  • \[{\mathcal{C}}_{t} \subseteq {\mathcal{E}}_{t} = \left\{ {\theta \in {\mathbb{R}}^{d} : {\begin{Vmatrix}\theta - {\widehat{\theta }}_{t - 1}\end{Vmatrix}}_{{V}_{t - 1}}^{2} \leq {\beta }_{t}}\right\} , \tag{19.7}\]
  • \(\mathcal{C}_{t} \) should contain \(\theta_\star\).
  • \(\mathcal{C}_{t} \) should be as small as possible.

    • Least-Squares Estimator of \(\theta_\star\)

  • The solution for \[{\widehat{\theta }}_{t} = {\operatorname{argmin}}_{\theta \in {\mathbb{R}}^{d}}\left( {\mathop{\sum }\limits_{{s = 1}}^{t}{\left( {X}_{s} - \left\langle \theta ,{A}_{s}\right\rangle \right) }^{2} + \lambda \parallel \theta {\parallel }_{2}^{2}}\right) , \tag{19.4}\]
  • is \[{\widehat{\theta }}_{t} = {V}_{t}^{-1}\mathop{\sum }\limits_{{s = 1}}^{t}{A}_{s}{X}_{s} \tag{19.5}\]
  • where \({V}_{0} = {\lambda I}\;\text{ and }\;{V}_{t} = {V}_{0} + \mathop{\sum }\limits_{{s = 1}}^{t}{A}_{s}{A}_{s}^{\top }. \tag{19.6}\)

    Stochastic Linear Bandits - LinUCB

    Theorem 19.2 Regret of LinUCB

  • With the probability \(1-\delta\), \[{\widehat{R}}_{n} \leq \sqrt{{8n}{\beta }_{n}\log \left( \frac{\det {V}_{n}}{\det {V}_{0}}\right) } \leq \sqrt{{8dn}{\beta }_{n}\log \left( \frac{{d\lambda } + n{L}^{2}}{d\lambda }\right) }.\] where \(\beta_n\) can be \[\sqrt{{\beta }_{n}} = \sqrt{\lambda }{m}_{2} + \sqrt{2\log \left( \frac{1}{\delta }\right) + d\log \left( \frac{{d\lambda } + n{L}^{2}}{d\lambda }\right) }, \tag{19.8}\] where \(m_2\) is an upper bound of \({\begin{Vmatrix}{\theta }_{ * }\end{Vmatrix}}_{2}\)

    • Lemma 19.4 Elliptical Potential Lemma

  • Let \({\begin{Vmatrix}{a}_{t}\end{Vmatrix}}_{2} \leq L < \infty\) for all \(t \in \left\lbrack n\right\rbrack ,{V}_{t} = {V}_{0} + \mathop{\sum }\limits_{{s \leq t}}{a}_{s}{a}_{s}^{\top }\), and \(t \in \left\lbrack n\right\rbrack ,{V}_{t} = {V}_{0} + \mathop{\sum }\limits_{{s \leq t}}{a}_{s}{a}_{s}^{\top }\). Then \[\mathop{\sum }\limits_{{t = 1}}^{n}\left( {1 \land {\begin{Vmatrix}{a}_{t}\end{Vmatrix}}_{{V}_{t - 1}^{-1}}^{2}}\right) \leq 2\log \left( \frac{\det {V}_{n}}{\det {V}_{0}}\right) \leq {2d}\log \left( \frac{\operatorname{trace}{V}_{0} + n{L}^{2}}{d\det {\left( {V}_{0}\right) }^{1/d}}\right) .\]

    • Proof of Theorem 19.2

  • Let \( {A}_{t}^{ * } = {\operatorname{argmax}}_{a \in {\mathcal{A}}_{t}}\left\langle {{\theta }_{ * },a}\right\rangle \) be an optimal action for round \( t \) and \( {r}_{t} \) be the instantaneous regret in round \( t \) defined by \[{r}_{t} = \left\langle {{\theta }_{ * },{A}_{t}^{ * } - {A}_{t}}\right\rangle .\] Let \( {\widetilde{\theta }}_{t} \in {\mathcal{C}}_{t} \) for which \( \left\langle {{\widetilde{\theta }}_{t},{A}_{t}}\right\rangle = {\operatorname{UCB}}_{t}\left( {A}_{t}\right) \) . Then \[\left\langle {{\theta }_{ * },{A}_{t}^{ * }}\right\rangle \leq {\mathrm{{UCB}}}_{t}\left( {A}_{t}^{ * }\right) \leq {\mathrm{{UCB}}}_{t}\left( {A}_{t}\right) = \left\langle {{\widetilde{\theta }}_{t},{A}_{t}}\right\rangle .\] Using Cauchy-Schwarz inequality, \[{r}_{t} = \left\langle {{\theta }_{ * },{A}_{t}^{ * } - {A}_{t}}\right\rangle \leq \left\langle {{\widetilde{\theta }}_{t} - {\theta }_{ * },{A}_{t}}\right\rangle \leq {\begin{Vmatrix}{A}_{t}\end{Vmatrix}}_{{V}_{t - 1}^{-1}}{\begin{Vmatrix}{\widetilde{\theta }}_{t} - {\theta }_{ * }\end{Vmatrix}}_{{V}_{t - 1}}\] \[ \leq 2{\begin{Vmatrix}{A}_{t}\end{Vmatrix}}_{{V}_{t - 1}^{-1}}\sqrt{{\beta }_{t}}. \tag{19.10}\] Since \( {r}_{t} \leq 2 \) and \( {\beta }_{n} \geq \max \left\{ {1,{\beta }_{t}}\right\} \), \[{r}_{t} \leq 2 \land 2\sqrt{{\beta }_{t}}{\begin{Vmatrix}{A}_{t}\end{Vmatrix}}_{{V}_{t - 1}^{-1}} \leq 2\sqrt{{\beta }_{n}}\left( {1 \land {\begin{Vmatrix}{A}_{t}\end{Vmatrix}}_{{V}_{t - 1}^{-1}}}\right) .\] Then, by Cauchy-Schwarz inequality, \[{\widehat{R}}_{n} = \mathop{\sum }\limits_{{t = 1}}^{n}{r}_{t} \leq \sqrt{n\mathop{\sum }\limits_{{t = 1}}^{n}{r}_{t}^{2}} \leq 2\sqrt{n{\beta }_{n}\mathop{\sum }\limits_{{t = 1}}^{n}\left( {1 \land {\begin{Vmatrix}{A}_{t}\end{Vmatrix}}_{{V}_{t - 1}^{-1}}^{2}}\right) }. \tag{19.11}\]

    Confidence Bound for Least-Squares Estimator \(\hat{\theta}_t\)

    Bound on \(||\hat\theta_t-\theta_\star||_{V_t}\) for large action sets

  • Assume a fixed \((A_t)_{t=1}^\infty\) in advance
  • Bound on \(\langle x,\hat\theta_t-\theta_\star\rangle\) for small action space: \[\mathbb{P}\left( {\left\langle {{\widehat{\theta }}_{t} - {\theta }_{ * },x}\right\rangle \geq \sqrt{2\parallel x{\parallel }_{{V}_{t}^{-1}}^{2}\log \left( \frac{1}{\delta }\right) }}\right) \leq \delta . \tag{20.2}\] Proof: assume \(\lambda=0\) and \(V_t\) is invertible, \[\left\langle {{\widehat{\theta }}_{t} - {\theta }_{ * },x}\right\rangle = \left\langle {x,{V}_{t}^{-1}\mathop{\sum }\limits_{{s = 1}}^{t}{A}_{s}{X}_{s} - {\theta }_{ * }}\right\rangle = \left\langle {x,{V}_{t}^{-1}\mathop{\sum }\limits_{{s = 1}}^{t}{A}_{s}\left( {{A}_{s}^{\top }{\theta }_{ * } + {\eta }_{s}}\right) - {\theta }_{ * }}\right\rangle\] \[= \left\langle {x,{V}_{t}^{-1}\mathop{\sum }\limits_{{s = 1}}^{t}{A}_{s}{\eta }_{s}}\right\rangle = \mathop{\sum }\limits_{{s = 1}}^{t}\left\langle {x,{V}_{t}^{-1}{A}_{s}}\right\rangle {\eta }_{s}.\] Since \({\left( {\eta }_{s}\right) }_{s}\) is 1-subgaussian, \[\mathbb{P}\left( {\left\langle {x,{\widehat{\theta }}_{t} - {\theta }_{ * }}\right\rangle \geq \sqrt{2\mathop{\sum }\limits_{{s = 1}}^{t}{\left\langle x,{V}_{t}^{-1}{A}_{s}\right\rangle }^{2}\log \left( \frac{1}{\delta }\right) }}\right) \leq \delta .\] And \(\mathop{\sum }\limits_{{s = 1}}^{t}{\left\langle x,{V}_{t}^{-1}{A}_{s}\right\rangle }^{2} = \parallel x{\parallel }_{{V}_{t}^{-1}}^{2}\) results in the inequality.
  • Bound on \(||\hat\theta_t-\theta_\star||_{V_t}\) for large action sets： \[\mathbb{P}\left( {{\begin{Vmatrix}{\widehat{\theta }}_{t} - {\theta }_{ * }\end{Vmatrix}}_{{V}_{t}} \geq 2\sqrt{2\left( {d\log \left( 6\right) + \log \left( \frac{1}{\delta }\right) }\right) }}\right) \leq \delta . \tag{20.3}\]

    • Martingales and the Method of Mixtures

  • Drop the assumption of fixed \((A_t)_{t=1}^\infty\) in advance
  • Define the Martingale \[{S}_{t} = \mathop{\sum }\limits_{{s = 1}}^{t}{\eta }_{s}{A}_{s}.\] Since \( {\widehat{\theta }}_{t} = {V}_{t}^{-1}\mathop{\sum }\limits_{{s = 1}}^{t}{X}_{s}{A}_{s} = {\theta }_{ * } + {V}_{t}^{-1}{S}_{t} \), we can separate the martingale \( {\left( {S}_{t}\right) }_{t} \) from \( {V}_{t} \) at the price of the introduction of a maximum: \[\frac{1}{2}{\begin{Vmatrix}{\widehat{\theta }}_{t} - {\theta }_{ * }\end{Vmatrix}}_{{V}_{t}}^{2} = \frac{1}{2}{\begin{Vmatrix}{S}_{t}\end{Vmatrix}}_{{V}_{t}^{-1}}^{2} = \mathop{\max }\limits_{{x \in {\mathbb{R}}^{d}}}\left( {\left\langle {x,{S}_{t}}\right\rangle - \frac{1}{2}\parallel x{\parallel }_{{V}_{t}}^{2}}\right) .\] The Cramer-Chernoff method leads to \[\mathbb{P}\left( {\frac{1}{2}{\begin{Vmatrix}{\widehat{\theta }}_{t} - {\theta }_{ * }\end{Vmatrix}}_{{V}_{t}}^{2} \geq \log \left( {1/\delta }\right) }\right) = \mathbb{P}\left( {\exp \left( {\mathop{\max }\limits_{{x \in {\mathbb{R}}^{d}}}\left( {\left\langle {x,{S}_{t}}\right\rangle - \frac{1}{2}\parallel x{\parallel }_{{V}_{t}}^{2}}\right) }\right) \geq 1/\delta }\right)\] \[\leq \delta \mathbb{E}\left\lbrack {\exp \left( {\mathop{\max }\limits_{{x \in {\mathbb{R}}^{d}}}\left( {\left\langle {x,{S}_{t}}\right\rangle - \frac{1}{2}\parallel x{\parallel }_{{V}_{t}}^{2}}\right) }\right) }\right\rbrack\] \[= \delta \mathbb{E}\left\lbrack {\mathop{\max }\limits_{{x \in {\mathbb{R}}^{d}}}{M}_{t}\left( x\right) }\right\rbrack . \tag{20.5}\]

    Optimal Design for Least-Squares Estimator \(\pi^*\)

    G-optimal Design

  • \[V\left( \pi \right) = \mathop{\sum }\limits_{{a \in \mathcal{A}}}\pi \left( a\right) a{a}^{\top },\;g\left( \pi \right) = \mathop{\max }\limits_{{a \in \mathcal{A}}}\parallel a{\parallel }_{V{\left( \pi \right) }^{-1}}^{2}. \tag{21.2}\]

    • D-optimal Design

  • \[f\left( \pi \right) = \log \det V\left( \pi \right)\]

    • Theorem 21.1 Kiefer-Wolfowitz Theorem

  • Assume that \( \mathcal{A} \subset {\mathbb{R}}^{d} \) is compact and \( \operatorname{span}\left( \mathcal{A}\right) = {\mathbb{R}}^{d} \) . The following are equivalent:
  • (a) \( {\pi }^{ * } \) is a minimiser of \( g \) .
  • (b) \( {\pi }^{ * } \) is a maximiser of \( f\left( \pi \right) = \log \det V\left( \pi \right) \) .
  • (c) \( g\left( {\pi }^{ * }\right) = d \) .
